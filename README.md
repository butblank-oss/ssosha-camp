# Sosha Camp

여자 2인과 강아지 2마리(가끔 동반)의 캠핑 준비 보드예요.

- **준비 보드**: 사야 해요 / 알아보는 중 / 구매 완료 / 원래 있던 것. 카드를 끌어서 옮기거나, 카드를 눌러 상태를 바꾸고 구매처·가격·활용도를 기록할 수 있어요.
- **고르는 법**: 아이스박스 용량, 식기 고르는 법, 캠핑장 전기 계산법, 겨울 안전 수칙, 강아지 동반 체크리스트를 담았어요.
- **중고·다나와**: 품목마다 당근, N플리마켓, 초캠장터(네이버 카페 검색), 다나와 인기순을 바로 열 수 있어요.
- **캠핑 기록**: 첫 캠핑 지출과 배운 점, 백업 파일 내보내기와 불러오기가 있어요.

기록은 브라우저 localStorage에 저장돼요. 다른 기기로 옮기려면 백업 파일을 쓰세요.
품목 데이터는 `data.js`에서 고칠 수 있어요.
