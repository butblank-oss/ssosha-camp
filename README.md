# Sosha Camp

여자 2인과 강아지 2마리(가끔 동반)의 캠핑 준비 사이트예요.

- **준비 보드**: 장비를 살수록 캠프 장면이 꾸며지고 레벨과 뱃지가 올라요. 카드를 끌어서 옮기고, 카드를 누르면 추천 제품 3개와 구매 기록을 볼 수 있어요.
- **고르는 법**: 아이스박스 용량, 식기, 전기, 겨울 안전, 강아지 동반 가이드에 더해 필수 품목 추천 제품표, 생활 매장 구매 경로, 베테랑 캠퍼 조언을 담았어요.
- **적재**: 미니 컨트리맨 F60 트렁크에 짐을 자동으로 쌓아보는 테트리스예요. 부피와 무게를 계산하고, 줄자로 잰 실측값으로 바꿀 수 있어요.
- **중고·다나와**: 당근, N플리마켓, 초캠장터, 다나와 인기순 바로가기예요.
- **캠핑 기록**: 첫 캠핑 지출과 배운 점, 백업 내보내기와 불러오기가 있어요.

파일: `data.js`(품목), `research.js`(제품 조사), `game.js`(성장 시스템), `pack.js`(적재), `app.js`(화면).
기록은 브라우저 localStorage에 저장돼요.
